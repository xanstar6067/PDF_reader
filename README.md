# PaperDesk PDF

Настольный просмотрщик и редактор PDF для Windows 10/11 x64. Русский интерфейс в стиле Acrobat: вкладки документов, навигация слева, инструменты справа. C#, .NET 10, WPF, открытый движок PDFium. Коммерческие лицензии и пробные PDF-библиотеки не требуются.

## Возможности

- Светлая и тёмная темы в стиле Windows: **Вид → Тема оформления → Как в Windows / Светлая / Тёмная**. Выбор сохраняется; системная тема следует настройке Windows. Панели, вкладки, закладки, выпадающие списки, подсказки и контекстные меню используют общие шаблоны без светлых градиентов и анимации появления системных панелей. Открытые элементы обновляются при смене темы. Цвет страниц PDF, миниатюр и аннотаций не меняется. Диалог печати использует выбранную тему; системные диалоги выбора файлов и свойства драйвера оформляет Windows.

- Несколько PDF во вкладках, открытие через проводник, аргументы командной строки и drag & drop. Файлы, открытые повторным запуском, попадают во вкладки уже работающего окна.
- Непрерывный просмотр с виртуализацией страниц и миниатюр. Масштаб 25–400%, по ширине, полноэкранный режим, поддержка DPI. При крупном масштабе видимая часть страницы рисуется в полном разрешении, без огромных растров в памяти.
- Начальный просмотр 3D PDF с U3D/PRC: D3D11, вращение/приближение/сдвиг, освещение и несколько режимов отображения. Модель видна на странице и в миниатюрах; интерактивное окно открывается кнопкой на странице или через **Вид → 3D-просмотр текущей страницы**.
- Иерархическое оглавление из PDF-закладок, переходы по внутренним ссылкам; внешние ссылки открываются только после подтверждения адреса.
- Поиск по всему текстовому слою с подсветкой всех совпадений на странице, учётом регистра и поиском слова целиком.
- Выделение мышью, копирование выделения и текста страницы.
- Замена и удаление текстового объекта с сохранением исходного шрифта, когда это возможно; добавление нового текста, несколько строк и кириллица.
- PDF-аннотации: заметка, маркер, подчёркивание, зачёркивание, прямоугольник, овал и карандаш, с выбором цвета и толщины линии. Это стандартные аннотации PDF, их видят Acrobat и другие программы. В списке видны все типы комментариев других программ (фигуры, штампы, рисунки и т. д.).
- Заполнение обычных AcroForm: текстовые поля, флажки, переключатели и редактируемые выпадающие поля. Нажмите поле инструментом «Выделить текст».
- Поворот, перемещение, добавление и удаление страниц. Импорт из другого PDF и извлечение диапазона в отдельный PDF.
- Новый пустой PDF, сохранение и «Сохранить как», отмена/повтор изменений, предупреждение о несохранённых изменениях.
- Подписанные PDF сохраняются инкрементальным обновлением: подписанная версия файла остаётся байт в байт прежней.
- Автосохранение: изменённые документы раз в минуту копируются в `%LOCALAPPDATA%\PaperDesk\Recovery`; после сбоя PaperDesk предложит восстановить их при запуске. Пароли не сохраняются. Непредвиденные ошибки записываются в `%LOCALAPPDATA%\PaperDesk\Logs\errors.log`.
- Собственный диалог печати с предпросмотром каждого листа, не зависящим от предпросмотра драйвера. Принтер и его свойства, поддерживаемые форматы бумаги, автоматическая/книжная/альбомная ориентация, копии, дуплекс, оттенки серого, смешанные диапазоны (например, `1, 3-5, 8`), чётные/нечётные страницы и обратный порядок. Режимы: **Размер**, **Постер**, **Несколько**, **Брошюра**. Печать идёт в фоне из копии документа.
- Защищённые PDF: запрос пароля, сохранение защиты и соблюдение прав документа.
- Недавние документы и восстановление последней страницы; параметры хранятся в `%LOCALAPPDATA%\PaperDesk\settings.json` и записываются сразу.

## Просмотр 3D PDF

В 3D-окне ЛКМ вращает модель, ПКМ или Shift+ЛКМ сдвигает её, колесо приближает, Home вписывает модель. Доступны виды спереди/сверху/изометрия, матовый/глянцевый/металлический/иллюстрационный/каркасный режимы, направление и рассеянная составляющая света, блеск, тёмный фон и сечение. Просмотр не изменяет PDF. На странице и при печати используется начальный ракурс; камера отдельного окна в PDF не сохраняется.

**Вид → Настройки 3D-графики** позволяет выбрать адаптер. По умолчанию приоритет дискретного ГП; если его нет, используется встроенный. Есть программный D3D11 (WARP). Выбор сохраняется и применяется при следующем открытии окна и новых предпросмотрах. Фактический адаптер отображается внизу 3D-окна; эта настройка касается 3D, обычный интерфейс WPF оформляется средствами Windows.

Поддержаны одна модель на странице, U3D без сжатия и PRC, геометрия треугольников и основные цвета. PRC учитывает иерархию сборки, размещение экземпляров и прототипов, локальные координаты, поворот и масштаб деталей. Проверены собранная и разнесённая модели из SolidWorks 2018. Если положение ресурса не удалось разрешить, окно предупреждает о деталях в собственных координатах. Полная совместимость Acrobat пока не достигнута: исходные камеры PDF, сжатый/прогрессивный U3D, текстуры, анимации, геометрия PRC без готовых треугольников и 3D JavaScript не поддерживаются. Поток PDF допускает отсутствие фильтра или FlateDecode. 3D-растр ограничен 2048 пикселями по длинной стороне, в том числе при печати.

## Печать и склейка постера

Нажмите **Ctrl+P**. В режиме **Размер** доступны вписывание, фактический размер, уменьшение только крупных страниц и свой масштаб 10–1000 %. Автоповорот страниц можно отключить; при фактическом размере и своём масштабе содержимое за областью печати обрезается. Меню **Файл → Масштаб печати** задаёт начальный режим для диалога.

Чтобы распечатать A1 частями на A4, выберите бумагу **A4**, откройте **Постер** и оставьте масштаб **100 %** для сохранения размеров оригинала. Программа автоматически рассчитает сетку с учётом полей принтера:

- **Поля под склейку** — отдельные белые полосы слева, сверху, справа и снизу, в миллиметрах; они добавляются внутри доступной области печати.
- **Нахлёст рисунка** — ширина повторяющегося изображения на соседних листах, отдельно от белых полей. Совместите повторяющийся рисунок при сборке.
- **Координаты листа** печатаются на верхнем и нижнем полях: `строка-столбец` от верхнего левого угла. В полотне 3×3 крайние углы — `1-1` и `3-3`; рядом указаны страница PDF и размер сетки. При включённых подписях верхнее и нижнее поле составляют минимум 5,3 мм.
- **Метки обрезки** отмечают углы изображения. Кнопки с координатами под предпросмотром позволяют открыть нужную плитку. Число листов меняется при изменении масштаба, полей, нахлёста или ориентации.

В режиме **Несколько** задайте число строк и столбцов (1–8), порядок страниц и рамки. **Брошюра** размещает по две страницы на стороне в порядке для сгиба, добавляя пустые страницы до числа, кратного четырём. Для автоматической печати обеих сторон нужен дуплекс; при автоматической альбомной ориентации предлагается переворот по короткому краю. Можно отдельно печатать лицевые и оборотные стороны вручную; способ переворота стопки зависит от принтера.

Пунктирные границы в предпросмотре не печатаются. Если драйвер не сообщает область печати, используются поля 5 мм с сообщением в диалоге. Без установленного принтера доступен предпросмотр A4/A3, а отправка задания отключена.

## Запуск и назначение по умолчанию

Запустите `artifacts\PaperDesk\PaperDesk.exe` после публикации. Переносите **всю папку**: рядом должны находиться PDFium и остальные файлы приложения.

Кнопка **«Приложение по умолчанию»** регистрирует приложение для текущего пользователя, без администратора, и открывает настройки Windows. Выберите PaperDesk PDF для `.pdf`. После регистрации не перемещайте папку приложения; если переместили, нажмите кнопку повторно. На Windows 10 при необходимости найдите `.pdf` в общем списке приложений по умолчанию.

```powershell
.\PaperDesk.exe "C:\Документы\Книга.pdf"
.\PaperDesk.exe "C:\Документы\Первый.pdf" "C:\Документы\Второй.pdf"
.\PaperDesk.exe /p "C:\Документы\Книга.pdf" # открыть диалог печати
```

Регистрация использует `HKCU\Software\Classes`, `HKCU\Software\PaperDesk\Capabilities` и `HKCU\Software\RegisteredApplications`. Выбор программы остаётся в системных настройках Windows; описание API: [Microsoft Learn](https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-default-apps-settings).

## Аннотации

Выберите инструмент справа: для маркера, подчёркивания и зачёркивания протяните мышью по тексту, для прямоугольника и овала — по странице, карандашом рисуйте с нажатой кнопкой. Цвет и толщина линии задаются на той же панели до рисования.

Инструментом **«Выделить текст»** щёлкните по аннотации, чтобы выделить её (или выберите её на вкладке «Заметки»):

- фигуры, рисунки и заметки перетаскиваются мышью, у прямоугольника и овала есть маркеры размера по углам;
- щелчок по цвету на панели перекрашивает выделенную аннотацию (кроме заметок: их значок всегда жёлтый);
- двойной щелчок или кнопка «Комментарий…» — текст комментария;
- Delete — удалить, Esc — снять выделение. Все изменения отменяются через Ctrl+Z.

Разметка текста (маркер, подчёркивание, зачёркивание) привязана к тексту и не перемещается.

## Работа с текстом

Выберите **«Редактировать текст»** и нажмите на текст. Изменяется выбранный объект PDF: исходный текст удаляется из страницы, новый вставляется в ту же позицию с тем же цветом, обводкой, преобразованием и режимом отрисовки (невидимый OCR-слой остаётся невидимым). Пустая строка удаляет объект.

Исходный шрифт сохраняется, если он может отобразить все символы нового текста. Для встроенного подмножества это символы, уже использованные этим шрифтом на странице. Иначе встраивается подмножество Segoe UI только с нужными символами — обычно несколько килобайт на правку. Символы, которых нет в Segoe UI (например, иероглифы), отклоняются с сообщением.

PDF хранит текст отдельными объектами, иногда по слову или букве. Здесь нет автоматической перевёрстки абзацев: длинная замена может выйти за границы строки. Это необходимо проверять визуально перед сохранением.

## Ограничения

- OCR сканов, полноценная перевёрстка абзацев, редактирование текста внутри вложенных Form XObjects, редактирование изображений, XFA-формы, создание/проверка цифровых подписей и экспорт в Word/Excel пока не реализованы. Сканированные PDF можно просматривать, печатать, комментировать и дополнять текстом.
- Подписи не создаются и не проверяются. В подписанном PDF изменения дописываются после подписанной версии: подпись остаётся проверяемой, но правки содержимого валидатор покажет как изменения после подписания. Удалённое в таком файле содержимое остаётся в предыдущей версии внутри файла.
- При замене текста межсимвольный интервал и горизонтальное масштабирование исходного объекта не переносятся.
- JavaScript документа не выполняется. Вычисляемые формы, зависящие от скриптов, не пересчитываются. Поля списка и кнопки отправки формы не поддерживаются.
- История хранит полные снимки PDF: до 20 состояний, ориентир 128 МБ; для очень большого файла сохраняется хотя бы последний снимок. История действует до закрытия вкладки.
- Печать выполняется растром в 200 DPI с ограничением памяти на страницу. Для сложных инженерных чертежей может потребоваться более высокое разрешение.
- Удаление/замена текста не является сертифицированным инструментом редактирования конфиденциальных данных (redaction).

## Разработка

На Windows с .NET 10 SDK и Visual Studio 2022/2026 Build Tools: MSVC x64, Windows SDK, C++ CMake tools. Нативные D3D11 DLL и отдельный декодер автоматически собираются из включённых исходников; скачивание зависимостей при этом не требуется.

```powershell
dotnet restore PDF_Reader/PDF_Reader.slnx --locked-mode
dotnet build PDF_Reader/PDF_Reader.slnx -c Release --no-restore
dotnet run --project PDF_Reader/PDF_Reader
dotnet run --project PDF_Reader/PDF_Reader.Tests -- artifacts/tests
# Дополнительно: проверка реальных 3D PDF, исходные файлы не изменяются
dotnet run --project PDF_Reader/PDF_Reader.Tests -- artifacts/tests --3d-samples "каталог PDF 3D"
# Регрессии PRC на сгенерированных моделях, без пользовательских чертежей
.\tools\Build-3D.ps1 -Test
```

Тестовый проект — исполняемый интеграционный harness без дополнительных test-framework зависимостей. Он генерирует реальные PDF (включая зашифрованные, AcroForm, подписанные и OCR-слой), проверяет PDFium, историю, подмножества шрифтов, инкрементальное сохранение, рендер фрагментов, раскладку печати, восстановление после сбоя и WPF. Не отправляет задания на физический принтер. В `artifacts/tests` сохраняются PDF и PNG интерфейса для визуальной проверки.

```powershell
.\tools\Publish.ps1                     # автономная Windows x64 сборка
.\tools\Publish.ps1 -FrameworkDependent # требуется .NET 10 Desktop Runtime
```

`Native` изолирует ABI PDFium; `Services` владеет PDF и ресурсами; `ViewModels` описывает состояние и команды; `Controls` отображает страницы; `Views` содержит стили и диалоги. Вызовы PDFium сериализованы для всех документов, но UI-поток читает состояние документа без ожидания этой блокировки. Исходный файл загружается в память и не блокируется. Изменения транзакционные; сохранение атомарное с проверкой внешних изменений файла.

Карта проекта и правила разработки находятся в побайтно одинаковых `AGENTS.md` и `CLAUDE.md`; обновлять оба файла вместе.

`Native3D/` содержит собственный D3D11/DXGI-рендер. `PaperDeskModelWorker.exe` — отдельный процесс чтения моделей, ограниченный 90 секундами и 2 ГБ памяти, с одним декодированием одновременно. Его исходники, nanoPRC (AGPLv3), zlib и самостоятельная CMake-сборка включены в `third-party` публикации. PdfPig 0.1.14 (Apache-2.0) используется для извлечения потоков из снимка документа. Все лицензии перечислены в `THIRD-PARTY-NOTICES.md`.
