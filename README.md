# PaperDesk PDF

Настольный просмотрщик и редактор PDF для Windows 10/11 x64. Русский интерфейс в стиле Acrobat: вкладки документов, навигация слева, инструменты справа. C#, .NET 10, WPF, открытый движок PDFium. Коммерческие лицензии и пробные PDF-библиотеки не требуются.

## Возможности

- Несколько PDF во вкладках, открытие через проводник, аргументы командной строки и drag & drop.
- Непрерывный просмотр с виртуализацией страниц и миниатюр. Масштаб 25–400%, по ширине, полноэкранный режим, поддержка DPI.
- Иерархическое оглавление из PDF-закладок, переходы по внутренним и внешним ссылкам.
- Поиск по всему текстовому слою с подсветкой, учётом регистра и поиском слова целиком.
- Выделение мышью, копирование выделения и текста страницы.
- Замена и удаление текстового объекта, добавление нового текста, несколько строк и кириллица.
- Стандартные PDF-аннотации: жёлтый маркер, заметки, список комментариев и удаление аннотаций.
- Заполнение обычных AcroForm: текстовые поля, флажки, переключатели и редактируемые выпадающие поля. Нажмите поле инструментом «Выделить текст».
- Поворот, перемещение, добавление и удаление страниц. Импорт из другого PDF и извлечение диапазона в отдельный PDF.
- Новый пустой PDF, сохранение и «Сохранить как», отмена/повтор изменений, предупреждение о несохранённых изменениях.
- Печать через стандартный диалог Windows: принтер, свойства драйвера, копии, все страницы, текущая страница или диапазон. Страницы вписываются в печатную область.
- Защищённые PDF: запрос пароля, сохранение защиты и соблюдение прав документа.
- Недавние документы и восстановление последней страницы; параметры хранятся в `%LOCALAPPDATA%\PaperDesk\settings.json`.

## Запуск и назначение по умолчанию

Запустите `artifacts\PaperDesk\PaperDesk.exe` после публикации. Переносите **всю папку**: рядом должны находиться PDFium и остальные файлы приложения.

Кнопка **«Приложение по умолчанию»** регистрирует приложение для текущего пользователя, без администратора, и открывает настройки Windows. Выберите PaperDesk PDF для `.pdf`. После регистрации не перемещайте папку приложения; если переместили, нажмите кнопку повторно. На Windows 10 при необходимости найдите `.pdf` в общем списке приложений по умолчанию.

```powershell
.\PaperDesk.exe "C:\Документы\Книга.pdf"
.\PaperDesk.exe "C:\Документы\Первый.pdf" "C:\Документы\Второй.pdf"
.\PaperDesk.exe /p "C:\Документы\Книга.pdf" # открыть диалог печати
```

Регистрация использует `HKCU\Software\Classes`, `HKCU\Software\PaperDesk\Capabilities` и `HKCU\Software\RegisteredApplications`. Выбор программы остаётся в системных настройках Windows; описание API: [Microsoft Learn](https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-default-apps-settings).

## Работа с текстом

Выберите **«Редактировать текст»** и нажмите на текст. Изменяется выбранный объект PDF: исходный текст удаляется из страницы, новый вставляется в ту же позицию с тем же цветом и преобразованием. Пустая строка удаляет объект. Шрифт заменяется на встраиваемый Segoe UI, поэтому доступны русские символы даже в документах с ограниченным набором исходных глифов.

PDF хранит текст отдельными объектами, иногда по слову или букве. Здесь нет автоматической перевёрстки абзацев: длинная замена может выйти за границы строки. Это необходимо проверять визуально перед сохранением.

## Ограничения

- OCR сканов, полноценная перевёрстка абзацев, редактирование текста внутри вложенных Form XObjects, редактирование изображений, XFA-формы, создание/проверка цифровых подписей и экспорт в Word/Excel пока не реализованы. Сканированные PDF можно просматривать, печатать, комментировать и дополнять текстом.
- Изменение подписанного PDF может нарушить цифровую подпись; наличие подписей отображается в свойствах и строке состояния.
- JavaScript документа не выполняется. Вычисляемые формы, зависящие от скриптов, не пересчитываются. Поля списка и кнопки отправки формы не поддерживаются.
- История хранит полные снимки PDF: до 20 состояний, ориентир 128 МБ; для очень большого файла сохраняется хотя бы последний снимок. История действует до закрытия вкладки.
- Печать выполняется растром в 200 DPI с ограничением памяти на страницу. Для сложных инженерных чертежей может потребоваться более высокое разрешение.
- Удаление/замена текста не является сертифицированным инструментом редактирования конфиденциальных данных (redaction).

## Разработка

На Windows с .NET 10 SDK:

```powershell
dotnet restore PDF_Reader/PDF_Reader.slnx --locked-mode
dotnet build PDF_Reader/PDF_Reader.slnx -c Release --no-restore
dotnet run --project PDF_Reader/PDF_Reader
dotnet run --project PDF_Reader/PDF_Reader.Tests -- artifacts/tests
```

Тестовый проект — исполняемый интеграционный harness без дополнительных test-framework зависимостей. Он генерирует реальные PDF (включая зашифрованные и AcroForm), проверяет PDFium, историю, атомарное сохранение и WPF. Не отправляет задания на физический принтер. В `artifacts/tests` сохраняются PDF и PNG интерфейса для визуальной проверки.

```powershell
.\tools\Publish.ps1                     # автономная Windows x64 сборка
.\tools\Publish.ps1 -FrameworkDependent # требуется .NET 10 Desktop Runtime
```

`Native` изолирует ABI PDFium; `Services` владеет PDF и ресурсами; `ViewModels` описывает состояние и команды; `Controls` отображает страницы; `Views` содержит стили и диалоги. Вызовы PDFium сериализованы для всех документов. Исходный файл загружается в память и не блокируется. Изменения транзакционные; сохранение атомарное с проверкой внешних изменений файла.

Карта проекта и правила разработки находятся в побайтно одинаковых `AGENTS.md` и `CLAUDE.md`; обновлять оба файла вместе.

| Следующее / предыдущее совпадение | F3 / Shift+F3 |

| Полный экран | F11 |
| Закрыть вкладку | Ctrl+W |
